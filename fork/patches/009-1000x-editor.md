# 009 — 1000x as an external editor

## Goal

Add 1000x (`~/repos/1000x`) to the external editors in Settings → Integrations on
macOS. ⌘+click on a diff line (patch 005) then opens the file at that line in
1000x, in the workspace that contains the file.

## Upstream link

- None. 1000x is a personal app.

## Touched files

- `app/src/lib/editors/darwin.ts` — new `1000x` entry in `editors`.
- `app/src/lib/editors/line-jump.ts` — `getEditorLineJumpURL` gets a `1000x`
  branch; new `getThousandXLineJumpURL`. This file comes from patch 005.

## Change summary

- `darwin.ts`: finds 1000x by its bundle id `com.astoilkov.1000x`. A plain
  "Open in 1000x" uses `open -a`, as for every other editor.
- `line-jump.ts`: 1000x has no `scheme://file/<path>:<line>` URL. Its
  `thousandx://open-url` link takes a `workspace` and a `url`, so
  `getThousandXLineJumpURL` sends the file path as the workspace and
  `file://<path>#L<line>` as the URL. `url` must be the last parameter, because
  1000x reads it as the rest of the query. Each path segment goes through
  `encodeURIComponent`, so a `#` or `?` in the path stays in the path.

## Needs from 1000x

The 1000x side is in its `prompt/app.md`, under "URL Scheme". Until 1000x
implements it:

- a ⌘+click opens the file as a browser tab, not as a code tab at the line.
- `open -a 1000x <path>` only brings 1000x to the front.

## Verify

1. `yarn build:dev && yarn start`.
2. In Settings → Integrations, select **1000x** as the external editor.
3. In the **Changes** tab, ⌘+click a diff line. 1000x opens the file in the
   workspace of the repository, with the cursor on that line.
4. Use **Repository → Open in 1000x**. 1000x opens the workspace of the
   repository.
